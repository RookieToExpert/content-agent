## 三、从对标里学到的铁律（持续更新）

1. **封面字和笔记标题必须分工（别写同一句话）**
   - **封面大字**负责建立体面的「身份/经验感」（例：*一些比较令我骄傲的 GitHub 使用经验*）；
   - **笔记标题**负责给直接的「利益/好奇心钩子」（例：*个人认为 github 搞钱最快的方式*）。
2. **技术题材切忌用浮夸营销号标题**
   - 林熙乐两篇 **10 页内页完全一样**的帖子：标题叫《每天vibe coding六七小时的心得总结》拿了 **1149 赞**；另一篇标题改成《不会vibe coding都给我去看啊啊啊！so easy》只有 **197 赞**（差了 5.8 倍）。想学 AI 造工具的读者信「老手真心得」，反感「啊啊啊 so easy」。
3. **藏赞比 > 1.2 的秘密：中后段必须有「一页能直接抄走的清单/流程」**
   - 前 3 页讲痛点和反差（骗停留），第 5～8 页给具体入口、步骤或防坑清单（骗收藏）。
