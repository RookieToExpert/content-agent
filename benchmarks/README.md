# 对标原帖库（Benchmarks）

这里只做两件事：
1. **各博主文件夹（`benchmarks/<博主名>/`）**：**100% 原样存放别人的原帖**（原图 `p01`～`pNN`、图上原文、帖子正文原文、评论原话），不掺杂二手分析。
2. **本页总表**：把抓回来的原帖按**「题材 / 卡片形式」**分类排好。我们自己写帖子时，直接从下面挑一篇对标原帖，照着它的卡片样式和节奏写我们自己的内容。

采集 SOP 见：[`benchmark-collect`](../.agents/skills/benchmark-collect/SKILL.md)。

## 二、怎么用这个库写我们自己的帖子？

不需要再看复杂的规律编号，每次写稿直接 **3 步走**：
1. **挑样板**：从上表挑一篇形式最搭的原帖（比如想写「个人数据库怎么搭」，就点开林熙乐的 10 页文字卡原帖）。
2. **替换成我们的真实素材**：对照原帖 P1～P10 每一页的字数和说话节奏，填入你自己的真实经历/数据，生成 `posts/<序号_标题>/post.md`。
3. **发帖 & 记数据**：发出去后把 d1/d3/d7 流量填回 `post.md`。
