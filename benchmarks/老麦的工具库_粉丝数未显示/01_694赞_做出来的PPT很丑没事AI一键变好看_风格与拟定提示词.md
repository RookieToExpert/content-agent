## 风格观察

以下综合画面审看，只概括整体做法，不按秒断言分镜（审看与录屏时间轴曾有冲突，除上一节转录时间段外不再给出场景时间点）。未推测原作者使用的剪辑软件、音色模型或是否为真人配音。

- 类型：软件实操录屏教程，无真人出镜或数字人。
- 画面：深色网格背景；以产品界面演示为主，间或插入偏办公/教师场景的库存风格配图；多次使用原版与美化版左右对照。
- 字幕与强调：底部白字描黑边的解说字幕；另有放大加粗的重点花字，配黄/红色块。
- 引导与剪辑：按钮与光标处拉近，辅以红色箭头；硬切与滑动转场；加载过程有加速处理。
- 声音：旁白节奏偏快、吐字清楚；有较轻的背景配乐，重点处带弹跳/掠过类音效。无法判断为人声还是合成声。
- 结构：痛点开场 → 方案预告 → 扩大受众痛点 → 实操步骤 → 前后对比 → 演示资产库的延伸用法 → 价值收束与行动号召。

## 原创制作提示词（拟定）

以下提示词是为用同一方法做一条**原创**教程而拟定的，不是原作者的实际提示词，也未还原其内部生成指令。方括号为可替换变量。功能、价格、是否免费等，只写事先核过的事实，不得编造。

### 1. 约 3 分钟口播脚本

```
请写一条约3分钟的中文工具教程口播，结构固定为：
1）用具体难看/难用的成品引出痛点（不超过20秒）；
2）点出解决方案，只预告可核验的效果，不把后文步骤说完；
3）把痛点扩到 [受众]，用他们的真实工作场景，不要空泛抱怨；
4）用已有素材演示 [工具] 的 [已核实功能]，按真实操作顺序写，步骤与界面名称必须可核验；
5）做原版与处理后的对照，说明对照要证明什么；
6）如需第二个功能，仅在 [已核实功能] 范围内写延伸用法；
7）收在“把时间还给专业内容”，加一句可核验的行动号召。

约束：
- 不要编造功能、效果、价格或“免费”承诺；未核验的权益一律不写。
- 不要模仿或复述任何已有博主的原句。
- 不要假装真人出镜；这是录屏+旁白。
- 变量示例：[工具]=将使用的产品名称；[受众]=如职场汇报者/教师/培训师；[已核实功能]=仅列入发布前已亲手验证的功能名称。
```

### 2. 分镜简报（时间 / 旁白 / 真实录屏 / 强调）

```
根据已定稿的3分钟口播，写一分镜表，每行包含：大致时间段、该段旁白要点、需要录到的真实软件界面、强调方式。
要求：
- 全程以真实产品界面录屏为主，不要用生成画面冒充产品UI。
- 开场给“内容已写完但版式差”的原稿，再进入工具操作。
- 操作段写清点击路径和光标/按钮需要拉近的位置，可用红箭头指示，不要臆造菜单名。
- 对照段用左右或前后对比，突出层级、分区和关键数字，不要只说“变好看了”。
- 转场可用硬切或滑动；加载、导出等等待过程允许加速，但须仍是真实界面。
- 时间是分镜规划，不是已测量的成片轴。
```

### 3. 剪辑与字幕规范（拟定参数，非实测）

```
请按下列拟定规范剪辑和加字幕（这些是建议值，不是对原片的测量结果）：
- 画幅：按发布平台导出 16:9；如源素材是 16:10 录屏，先裁切或加底，避免界面变形。
- 底字幕：画面底部居中，白字黑描边，每行不超过 16–18 个汉字，随旁白切换。
- 重点花字：关键词放大加粗，可用黄或红底色块；同时出现的花字不超过 2 处。
- 指示：要点击的按钮做短促拉近，必要时加红色箭头，停留约 0.5–1 秒。
- 节奏：操作段紧凑，等待画面加速；不要用未经验证的转场插件名称。
- 配乐：低音量轻节奏垫乐，重点处可加轻微掠过/弹跳音效，不得压过旁白。
```

### 4. 可选 AI 空镜（不得假冒产品界面）

```
如需补充空镜，只生成与主题相关的办公、教室或思考氛围画面，用作过场，不得出现可被误认为 [工具] 产品界面、按钮、数据或品牌皮肤的内容。
不要生成真人面孔去扮演作者，也不要生成“AI正在美化PPT”的假界面。
产品演示必须来自真实软件录屏。
```

### 5. 配音

```
使用已获授权的通用 TTS 音色朗读定稿口播：中文，语速偏快但吐字清楚，语气是讲解而非夸张带货。
不要克隆任何创作者或未授权人物的声音。
若无法确认授权，改为自己配音。
```
