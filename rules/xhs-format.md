## 三种验证过的封面（看过实图，图在 library/batches/assets/2026-11-11-ai-discovery/）

| 风格 | 实例 | 适合 |
|---|---|---|
| **真人 + 场景 + 超大粗体字** | 「提示词这样写 AI更懂你」10.8 万赞（ai-most-liked-all-filter.png）：真人坐在复古电脑前、暖色调、黄白两色粗体大字占半屏 | 大众引流，上限最高；需要出镜和拍摄 |
| **极简文字卡 + 栏目编号** | Elaine #02「3分钟拆一个AI产品」（6a0eed1f…-cover.png）：白底、编号、阅读时长承诺、居中 logo、底部署名 | 系列/合集识别、干货；成本最低 |
| **奶黄底金句卡** | 林熙乐「一些比较令我骄傲的GitHub使用经验」（6ae0a523…-cover.png）：引号装饰、关键词高亮、像一句自述 | 个人经验、口吻感 |
| 手绘可爱 | 阿T 手绘小猫图标 + 手机样机（69c26610…-body.jpg） | 生活、产品 |

**封面字和笔记标题分工**：林熙乐封面写「令我骄傲的GitHub使用经验」（口吻、身份），笔记标题写「个人认为github搞钱最快的方式」（利益点）。封面负责让人停下，标题负责让人点开，不要写成一样的。

## 由此得出的做法

- **封面**：纯色浅底 + 黑色大字 + 一个强调色；系列用统一版式和角标（如「被AI包养的第N天」）
- **每页一个要点**，字大到手机上不用放大
- **不放原始截图**（GitHub、终端、后台）；要展示的东西重新做成卡片（日程表、大数字、聊天气泡）
- **至少一页「能直接拿走」**：一句可复制的提示词、一份清单、一个模板——样本里这类收藏常高于点赞
- 技术细节点到为止，给普通人可选的替代方案（手机 / 表格 / 程序员版）
