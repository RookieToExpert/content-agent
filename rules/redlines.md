# 发布红线

任何一条不满足都不能进入 `approved`。`scripts/check_draft.py` 能自动查一部分（标 🤖），其余必须人看。

## 1. 工作信息脱敏

- 🤖 不出现公司、客户、合作方名称，及内部域名（脚本里有关键词表 `rules/redline_terms.txt`，可自行追加）
- 🤖 不出现 IP 地址、内网主机名、集群名/节点名样式的字符串
- 🤖 不出现形似密钥、token、AK/SK 的长串
- 排障案例只讲**通用问题和判断方法**，改掉能定位到具体环境的细节（规模数字取整、时间模糊化、组件只写开源名）
- 截图必须打码：终端里的主机名、IP、用户名、路径中的公司名、浏览器标签和地址栏
- 不讲未公开的事故、客户、内部人员

## 2. 平台规则（小红书）

- 🤖 标题 ≤20 字，正文 ≤1000 字
- 🤖 正文不出现站外引流：微信号、二维码描述、「加 V」「vx」、外部网址
- 不直接写价格和购买链接；产品露出用「主页/私信口令」方式
- 不用绝对化用语（最、第一、100%）描述产品效果

## 3. 真实性

- 产品功能只写 `products.md` 里有的
- 数据和结果必须来自真实经历；估算要写明是估算
- 不冒充他人经历，不夸大自己的职位和经验

## 4. 版权

- 不整段搬运他人帖子；参考了谁的结构不需要标注，但引用他人观点或数据要注明来源
