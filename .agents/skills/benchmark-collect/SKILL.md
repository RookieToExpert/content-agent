# benchmark-collect：对标原帖完整归档 SOP

本 Skill 用于将小红书等平台的垂直对标帖子**原汁原味搬运归档**到 `benchmarks/`，供人和 AI 写稿时直接看着原帖模仿创作。

## 核心原则（所有 Agent 必守）

1. **帖子文件只存「100% 原始帖子内容」，绝不掺杂 AI 分析！**
   - 单篇帖子 Markdown 里**只放**：基础互动数据、原帖正文原文、每一页的原图 + 图上原始文字（或视频分镜截图 + 原版口播逐字稿）、评论区原始评论。
   - **禁止**用 AI 的概括（如“第 2 页讲了用户痛点”）代替原图上的真实文字！**禁止**在单篇帖子文件里写长篇分析、结构拆解或免责声明。
2. **禁止使用乱码 ID 做文件名！**
   - 博主目录：`benchmarks/<博主名>_<粉丝数>粉/`（例：`benchmarks/林熙乐_350粉/`）
   - 帖子文件：`<序号>_<赞数>赞_<原帖标题>.md`（例：`01_1794赞_个人认为github搞钱最快的方式.md`）
3. **必须存齐每一页原图（`p01.png`～`pNN.png`）！**
   - 绝不能只存封面图。图文帖的每一页轮播图都必须保存到 `benchmarks/<博主目录>/assets/<序号>/p01.png`、`p02.png` … `pNN.png`。

---

## 本地浏览器抓取 4 步 SOP（给 Codex 执行）

### 第 1 步：采集博主主页（`benchmarks/<博主名>_<粉丝数>粉/README.md`）

1. 截取主页头部信息（昵称、简介、粉丝、获赞与收藏），存为 `assets/profile.png`。
2. 客观列出主页可见笔记列表（标题、原链、赞数、是否已归档原帖）。

### 第 2 步：进入单篇帖子，保存全部图片与原始文本

在浏览器打开目标帖子详情页，依次获取：
1. **互动数据裁片**：存为 `assets/<序号>/metrics.png`（含作者、赞、藏、评数字）。
2. **原帖正文区**：**一字不改**复制笔记标题、完整正文段落、底部全部 `#话题` 标签、页面显示的发布/编辑日期与地点。
3. **全部内页图片与图上原文**：
   - **图文帖**：点击轮播图从第 1 页翻到最后一页，将每一页原图保存为 `assets/<序号>/p01.png`、`p02.png` … `pNN.png`；同时**把每一页图片上的文字一字不漏地照抄下来**（保留原图的标题、正文、列表层级）。
   - **视频帖**：保存封面 `assets/<序号>/cover.png` 及关键画面截图 `s01.png`…，并将**视频完整口播台词/字幕一字不漏转录为逐字稿**。
4. **原始评论**：复制前 10～20 条真实读者评论的**原话**（跳过机器人总结和广告）。

### 第 3 步：按「纯原帖模板」写入文件

生成 `benchmarks/<博主目录>/<序号>_<赞数>赞_<原帖标题>.md`，格式固定如下（只放原始内容，不写分析）：

```markdown
# <原帖标题>

[⬅ 返回博主主页](./README.md) · [返回对标总览](../README.md) · [小红书原帖链接](<url>)

## 一、基础数据

- **作者**：<博主名>（<粉丝数> 粉）
- **数据**：<赞> 赞 · <藏> 藏 · <评> 评
- **时间**：<页面显示日期>
- **形式**：图文（共 N 页） / 视频（时长 X:XX）

![互动数据](assets/<序号>/metrics.png)

## 二、帖子正文与话题（原文）

<一字不改粘贴帖子正文>

<一字不改粘贴 #话题1 #话题2 ...>

## 三、全部内页原图与图上原文（共 N 页）

| 页码 | 原图 | 图上原始文字（逐字转录） |
|---|---|---|
| **P1** | <img src="assets/<序号>/p01.png" width="260" /> | <原图第1页上的全部文字> |
| **P2** | <img src="assets/<序号>/p02.png" width="260" /> | <原图第2页上的全部文字> |
...

## 四、评论区原始留言摘录

- **读者 A**：「<评论原话>」
  - **作者回复**：「<如有，贴原话>」
- **读者 B**：「<评论原话>」
```

### 第 4 步：在 `benchmarks/README.md` 登记一行分类索引

在 `benchmarks/README.md` 的总表里加一行（所属分类、卡片样式、链接），方便写新帖时直接按分类挑一篇原帖照着写。
